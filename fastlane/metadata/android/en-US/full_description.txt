Husk is a minimal Android launcher: text instead of icons, a pixel typeface that also covers Arabic, and enough of a phone built in that you rarely leave the home screen.

It is a personal project, published because it works well enough to use every day, not because it is finished. The README lists what is still rough.

FEATURES

* Home screen with up to 8 apps in a two-column grid, optional clock, date and screen time.
* App drawer: swipe up and type to filter. Auto-launch fires when exactly one app matches.
* Dialer: swipe down for a searchable contact list and recent calls. Search by name or number.
* Media controls on the home screen, driving VLC or any player exposing a media browser service.
* Notifications: newest one on a single home screen line, tap to open and dismiss. Full panel with swipe-to-dismiss.
* Per-app internet blocking. Pick apps and they lose network access, using a local VPN, no root.
* Quotes: one short line on the home screen, a new one each unlock, tap for another. Bundled, no network.
* Backgrounds: device wallpaper, solid colour, gradient, or your own image.
* Voice recorder: both volume keys at once, or a quick settings tile, records from the lock screen or with the screen off. Recordings stay in the app's private storage and never leave the device.
* Full Arabic support in a matching pixel typeface. This is why the fork exists.

PRIVACY

No analytics, no crash reporter, no account, no server. Contacts, notifications and usage statistics are read on device and never leave it.

One optional feature touches the network. Internet blocking runs a local VPN that drops blocked apps' packets; it has no remote endpoint and logs nothing, though Android will still warn you that a VPN "can monitor network traffic" because that is what the API grants in general.

KNOWN LIMITS

* Android permits one active VPN, so app blocking and a real VPN cannot run together.
* Translations are inherited from Olauncher and cover only the older UI. Everything Husk added is English only.
* Tested on one device running Android 15.

Husk is a fork of Olauncher by tanujnotes, GPL-3.0.
